# Enzo Dutervil Zoccherato — Portfolio V4

Portfolio em React + TypeScript + Vite.

## Novidades da V4

- Site bilíngue PT-BR / English com seletor no cabeçalho.
- Idioma escolhido fica salvo no navegador.
- Currículo em português e resume em inglês, baixados conforme o idioma selecionado.
- Nível de inglês atualizado para **Intermediário / Intermediate**.
- Tema claro/escuro, cases técnicos, certificações e layout responsivo mantidos.

## Executar

```bash
npm install
npm run dev
```

## Validar build

```bash
npm run build
```
